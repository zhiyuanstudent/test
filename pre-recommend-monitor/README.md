# 2027 计算机类预推免每日监控

该目录用于自动监控高校和科研院所官网中的预推免、推免预报名、接收推荐免试、直博、校园开放日、优秀大学生夏令营和选拔营通知。

## 自动运行

GitHub Actions 在**北京时间每天 09:00**自动运行一次，也可以在 Actions 页面手动运行。工作流会：

1. 从学校研究生招生网和计算机相关学院的官方入口开始抓取；
2. 沿官网中的“研究生招生、招生信息、推免、夏令营”等栏目向内遍历；
3. 校验最终页面仍属于该校官方域名，过滤无关专业和校内推免资格公示；
4. 提取报名、材料提交、截止、复试、面试和考核时间；
5. 与历史状态对比，识别新增通知或关键时间变化；
6. 更新日报，并在发现变化时创建 GitHub Issue 提醒 `@zhiyuanstudent`。

程序不依赖百度、必应等公共搜索结果页，避免 GitHub 海外节点触发验证码或返回地域化无关结果。

## 查看结果

- `data/latest.md`：最近一次完整日报；
- `data/alerts.md`：最近一次新增或变更；
- `data/state.json`：历史去重状态；
- `official_seeds.yml`：各校研究生院和计算机相关学院的官方抓取入口；
- `schools.yml`：学校范围、关键词和运行参数。

## 当前范围

首批覆盖 58 所高校和科研单位，包括此前重点关注的国防科技大学、西北工业大学、西安交通大学、厦门大学、南开大学、中山大学、南京理工大学、北京邮电大学、东北大学、华中科技大学、吉林大学、中国科学院大学及计算所、自动化所、软件所、信工所、深圳先进院，同时覆盖主要 985 高校和部分计算机强校。

增加学校时，在 `schools.yml` 中添加学校名称和官方根域名，并在 `official_seeds.yml` 中添加研究生招生网、计算机学院或人工智能学院入口。

## 重要说明

- 学校官网可能把关键日期放在 PDF、Word、图片或报名系统中，自动提取可能遗漏；任何报名操作都必须以官网原文和附件为准。
- `即将截止` 表示程序识别到截止日期且剩余不超过 3 天；`待确认` 表示页面相关，但未可靠识别截止日期。
- 目标招生年份由程序按日期自动判断：每年 3 月以后默认监测下一招生年度，因此 2026 年下半年默认监测 2027 推免。
- 官网改版或临时不可访问时，日报中的“抓取状态”会显示异常，便于及时修正入口。
