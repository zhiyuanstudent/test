# 2027 计算机类预推免每日监控

该目录用于自动监控目标院校官网中的预推免、推荐免试、推免预报名、直博、校园开放日和选拔营通知。

## 运行方式

GitHub Actions 每天自动执行一次，并支持在 Actions 页面手动运行。程序同时采用：

1. 直接抓取学院或研究生招生官网的通知入口；
2. 通过 Bing RSS 对官方域名进行限定搜索，补充抓取不在首页展示的通知。

结果保存在：

- `data/latest.md`：最近一次完整报告；
- `data/state.json`：历史去重状态。

发现新增或关键时间发生变化时，工作流会自动创建 GitHub Issue，并 `@zhiyuanstudent` 提醒。

## 增加学校

编辑 `schools.yml`，为学校增加官方域名和官网入口即可。学校官网改版或某个入口失效时，日报的“抓取状态”会显示警告，但官方域名搜索仍会继续作为备用通道。

## 注意

程序会自动提取报名截止、复试、面试等时间，但附件中的日期可能无法完整解析。任何报名操作都应以官网原文和附件为准。
