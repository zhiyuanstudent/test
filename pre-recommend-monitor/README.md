# 2027 计算机类预推免每日监控

该目录用于自动监控高校和科研院所官网中的预推免、推免预报名、接收推荐免试、直博、校园开放日、优秀大学生夏令营和选拔营通知。

## 自动运行

GitHub Actions 在**北京时间每天 09:00**自动运行一次，也可以在 Actions 页面手动运行。工作流会：

1. 对每所学校的官方域名进行限定检索；
2. 访问候选官网页面并核验域名；
3. 提取报名、材料提交、截止、复试、面试和考核时间；
4. 与历史状态对比，识别新增通知或关键时间变化；
5. 更新日报，并创建 GitHub Issue 提醒 `@zhiyuanstudent`。

## 查看结果

- `data/latest.md`：最近一次完整日报；
- `data/alerts.md`：最近一次新增或变更；
- `data/state.json`：历史去重状态。

## 当前范围

首批覆盖 58 所高校和科研单位，包括你此前重点关注的国防科技大学、西北工业大学、西安交通大学、厦门大学、南开大学、中山大学、南京理工大学、北京邮电大学、东北大学、华中科技大学、吉林大学、中国科学院大学及计算所、自动化所、软件所、信工所、深圳先进院，同时覆盖主要 985 高校和部分计算机强校。

完整清单位于 `schools.yml`。增加学校时，只需添加学校名称和官方根域名。

## 重要说明

- 学校官网可能把关键日期放在 PDF、Word、图片或报名系统中，自动提取可能遗漏；任何报名操作都必须以官网原文和附件为准。
- `即将截止` 表示程序识别到截止日期且剩余不超过 3 天；`待确认` 表示页面相关，但未可靠识别截止日期。
- 目标招生年份由程序按日期自动判断：每年 3 月以后默认监测下一招生年度，因此 2026 年下半年默认监测 2027 推免。
